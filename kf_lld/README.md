# KF32A158xxxSF_LLD (Low Level Driver)接口库

芯旺微电子开发的适用于 KF32A158xxxSF 系列芯片的底层驱动库. LLD库旨在为用户提供底层寄存器驱动接口, 方便用户更高效、便捷地进行功能开发. 

---
## 模块
包含所有外设模块的寄存器表, 寄存器驱动以及必要的宏定义.

## 文档结构
- **reg**: 该文件夹包含了所有外设模块的寄存器表. 
- **drv**: 该文件夹包含了所有外设模块的寄存器驱动. 
- **README.md**: 说明文档

## 注意事项
- 若LLD库内存在带deprecated属性修饰的LLD接口时, 可能将在下一个minor版本发布时移除, 请及时更新工程中使用到的原有LLD接口.
